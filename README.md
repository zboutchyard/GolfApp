Branch naming needs to be have the JIRA story number followed by a description of the issue/feature you are working on. 

SPRINT-123/addModal-profile-view

SPRINT-335/fix-duplicated-views



Once you have created the new branch, go into your terminal and run the following commands. 

git checkout main
git pull
git checkout *your branch name here*

Now you can start working in that branch. 



IMPORTANT NOTES: 

Merge conflicts are common and happen on a weekly basis when collaborating with a team. If you encounter a merge conflict, reach out to me and I will walk you through how to resolve some of these issues without breaking other features.

Never push directly to main branch. All merges to main should happen after pull requests have been reviewed and approved.
